FastAPI endpoints with domain routers + real-time streaming via WebSocket

API Endpoints
BASE URL: /api/v1

━━━ CORE ANALYSIS ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
POST /analyze              Main quote analysis (text input)
     Body: { query, domain?, city, country, quoted_price? }
     Returns: { verdict, price_range, confidence, explanation,
                red_flags[], questions[], negotiation_script }

POST /analyze/image        Photo of bill/invoice/damage
     Body: multipart { image, domain?, city, country }
     Returns: same as /analyze + extracted_text

POST /analyze/voice        Voice note input
     Body: multipart { audio, language? }
     Returns: { transcript } + same as /analyze

WS   /ws/analyze           WebSocket — streams verdict in real-time
     Send: { query, domain?, city, country, quoted_price? }
     Receive: stream of { step, data } events:
       → { step: "classifying", domain: "auto" }
       → { step: "searching", sources: 12 }
       → { step: "analyzing", model: "sonnet" }
       → { step: "verdict", data: { ...full result } }

Query Processing Pipeline (What happens on POST /analyze)

Pipeline Flow — Cost-Optimal Cascade
User Input: "Mechanic quoted ₹14,000 for brake pads + rotors, Honda City 2019, Pune"
                │
                ▼
┌─── STEP 1: CLASSIFY (Claude Haiku — ~0.2s, ~₹0.01) ──────────────┐
│  Extract: domain=auto, service=brake_pads+rotors, make=Honda,     │
│           model=City, year=2019, city=Pune, country=IN,           │
│           quoted_price=14000, currency=INR                         │
└───────────────────────────┬────────────────────────────────────────┘
                            │
                            ▼
┌─── STEP 2: CACHE CHECK (Redis + Supabase — ~0.1s, ₹0) ───────────┐
│  Redis key: "auto:brake_pads_rotors:honda_city:pune:IN"           │
│  Hit? → Return cached result (80% hit rate target)                 │
│  Miss? → Continue to Step 3                                        │
└───────────────────────────┬────────────────────────────────────────┘

Domain Prompt Templates (What makes each vertical smart)

🔧 Auto Repair

  • OEM vs aftermarket part distinction
  • Labor rate by city + garage tier
  • VIN/make/model/year specific pricing
  • Wear item vs repair classification
  • Red flags: unnecessary part replacement, bundled services

💊 Medical / Prescription

  • Generic vs branded drug lookup (NPPA database)
  • Standard-of-care validation (is this drug necessary?)
  • Drug interaction warnings
  • CGHS rate schedule comparison
  • Red flags: unnecessary medications, overpriced branded generics

🏠 Home Services

  • Material cost breakdown (cement, tiles, pipes by city)
  • Labor rate by skill level + city
  • Scope validation (is this job description reasonable?)
  • Seasonal pricing adjustments
  • Red flags: inflated material costs, vague scope, padding

⚖️ Legal (Phase 1)

  • Bar Council fee guidelines by court
  • Matter type classification (civil/criminal/corporate)
  • Free legal aid eligibility check
  • Standard fee schedule comparison
  • Red flags: unnecessary filings, inflated court fees
