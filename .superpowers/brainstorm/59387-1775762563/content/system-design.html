Cost-Optimal Data Extraction Strategy

Every query follows a cascading cost ladder — cheapest source first, expensive only when needed

Tier 1 — Free / Near-Free

  • Supabase cache — previous queries, community data ($0)
  • Redis cache — hot queries, 24h TTL ($0 on Upstash free)
  • Static knowledge base — NPPA drug prices, CGHS rates, OEM part catalogs ($0, scraped once)
  • Claude Haiku — intent classification, simple lookups ($0.25/1M tokens)

~80% of queries resolved here

Tier 2 — Low Cost

  • Tavily search — 1000 free/mo, then $0.01/search
  • Claude Sonnet — standard analysis + verdict ($3/1M tokens)
  • Community data merge — pgvector similarity search ($0)

~15% of queries need this

Tier 3 — Medium Cost

  • SerpAPI — fallback search, $50/mo for 5000 searches
  • GPT-4o Vision — invoice/bill photo analysis
  • Claude Opus — complex multi-domain reasoning

~4% of queries need this

Tier 4 — Expensive (On-Demand)

  • Firecrawl deep scrape — new vendor sites, price aggregators
  • Batch scraping jobs — scheduled, not per-query
  • Voice transcription — Whisper API for recordings

~1% of queries + scheduled batch jobs

Estimated cost per query: ~₹0.50-2.00 for 95% of queries (cache hit + Haiku/Sonnet). Heavy queries with Vision + Opus + Firecrawl: ~₹8-15. At 10K queries/day = ~₹5,000-15,000/day operational cost.
